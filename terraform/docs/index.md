# megooflags Provider

Manages MegooFlags projects, flags, targeting, segments and SDK keys through the REST API.

Resources:

- projects and their environments (`megooflags_project`);
- flags and their variations (`megooflags_flag`);
- a flag's targeting in one environment (`megooflags_flag_environment`);
- segments (`megooflags_segment`);
- SDK keys (`megooflags_sdk_key`).

The provider calls the management REST API with an API token. Every resource supports `terraform import`.

Terraform cannot change flags in an environment whose `approvals_required` is above 0: the API refuses the change, and the provider says so. Make those changes through a change request outside Terraform.

## Installation

The provider is not in the Terraform Registry. Each release, tagged `terraform/vX.Y.Z`, is on the [GitHub releases page](https://github.com/mmhy2003/MegooFlags/releases) as `terraform-provider-megooflags_X.Y.Z_<os>_<arch>.zip`, with a `SHA256SUMS` file. Install it into a filesystem mirror:

1. Download the archive for your system and check it against `SHA256SUMS`.
2. Unzip it into `~/.terraform.d/plugins/registry.terraform.io/mmhy2003/megooflags/X.Y.Z/<os>_<arch>/`, for example `~/.terraform.d/plugins/registry.terraform.io/mmhy2003/megooflags/0.1.0/linux_amd64/`.
3. Tell Terraform to use the mirror for this provider in its CLI configuration (`~/.terraformrc`, or `terraform.rc` in `%APPDATA%` on Windows). The path must be absolute:

```terraform
provider_installation {
  filesystem_mirror {
    path    = "/home/you/.terraform.d/plugins"
    include = ["registry.terraform.io/mmhy2003/megooflags"]
  }
  direct {
    exclude = ["registry.terraform.io/mmhy2003/megooflags"]
  }
}
```

Then require the provider with that source and version:

```terraform
terraform {
  required_providers {
    megooflags = {
      source  = "registry.terraform.io/mmhy2003/megooflags"
      version = "0.1.0"
    }
  }
}
```

## Example Usage

```terraform
terraform {
  required_providers {
    megooflags = {
      source = "registry.terraform.io/mmhy2003/megooflags"
    }
  }
}

# url and token fall back to MEGOOFLAGS_URL and MEGOOFLAGS_API_TOKEN.
provider "megooflags" {
  url = "https://flags.example.com"
}
```
